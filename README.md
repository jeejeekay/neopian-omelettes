# Neopian Omelettes

A Minecraft mod that adds 17 powerful omelettes, each eaten in three bites. By IGoByJake.
Download: https://modrinth.com/mod/neopian-omelettes

**The code lives on one branch per Minecraft version** — pick the branch from the dropdown above:

| Branch | Minecraft |
|---|---|
| [`mc/26.3`](../../tree/mc/26.3) | 26.3 (newest) |
| [`mc/26.2`](../../tree/mc/26.2) | 26.2 |
| [`mc/26.1`](../../tree/mc/26.1) | 26.1.x |
| [`mc/1.21.11`](../../tree/mc/1.21.11) | 1.21.11 |

Each branch has a `fabric/` and a `neoforge/` folder (separate Gradle projects) and its own README.
Build + test results for every push: the **Actions** tab.
